# Laurier BSA operations

Working folder for the Laurier Bangladeshi Students' Association exec: plans, specs, the changelog, and the SU rulebook. Private.

| Folder | What's in it |
|---|---|
| `plans/` | `TRACKER.md` (work list), `CHANGELOG.md` (one entry per finished item), `specs/` (build specs and decision notes), `drafts/` |
| `Plan MDs/` | Term plan and one plan per team (Presidents, Technology, Operations, Events, Finance, Outreach, Creative, Photography, Marketing) |
| `SU Policies 2026-27/` | Students' Union club training decks (2026-27): the rulebook for events, food, money, posters and hiring |
| `CLAUDE.md`, `.claude/` | Instructions and helper agents for Claude Code |

The photo gallery code lives in its own repo: [Laurier-BSA/photo-storage](https://github.com/Laurier-BSA/photo-storage). See its `PIPELINE.md`.

GitHub updates only when someone pushes. Edit on the Mac, then commit and push.
